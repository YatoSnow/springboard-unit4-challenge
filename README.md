# London Housing Price Analysis — Springboard Unit 4 Challenge (Tier 3)

An independent data science challenge from the Springboard Data Science Fellowship. This Tier 3 notebook requires solving a real-world analytical problem from scratch using only pandas, Matplotlib, and core Python — no scaffolding, no filled-in answers.

---

## Problem Statement

> *Which boroughs of London have seen the greatest increase in housing prices, on average, over the last two decades?*

London is divided into 32 boroughs, each with distinct desirability and pricing dynamics. This project investigates how those prices have shifted over time and which boroughs have experienced the sharpest appreciation.

---

## Approach

The project follows the four-stage data science pipeline:

1. **Sourcing and loading** — import and inspect the London housing dataset
2. **Cleaning, transforming, and visualizing** — tidy the data, handle dates, reshape as needed, and visualize distributions
3. **Modeling** — apply grouping, aggregation, and comparative analysis across boroughs
4. **Evaluating and concluding** — summarize findings and identify the highest-appreciating boroughs
